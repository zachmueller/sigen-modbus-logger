# Third-party notices

This project has no runtime dependencies — it is Python standard library only.
One *data* file is derived from third-party source, and its licence travels with it.

## `regmap.json`

`regmap.json` is generated by [`regmap_gen.py`](regmap_gen.py) from
`custom_components/sigen/modbusregisterdefinitions.py` in
[TypQxQ/Sigenergy-Local-Modbus](https://github.com/TypQxQ/Sigenergy-Local-Modbus),
a Home Assistant integration. The generator parses that file with `ast` — it imports
`homeassistant`, so it cannot simply be imported — and flattens the register
dataclasses, alarm-code appendices and enums into JSON. Register addresses, data
types, gains, units and descriptions come from there; the block plan, decode
conventions and everything else in this repository do not.

## Register semantics

The meaning of the registers themselves — addresses, scaling, alarm bit tables — 
originates in Sigenergy's own published Modbus protocol documentation. This project
does not redistribute that document. Where its typing is wrong for a real unit, the
correction is annotated in `lib.DTYPE_OVERRIDE` rather than silently applied.
